# AI Summarizer

AI Summarizer is a personal web application for processing long-form content using AI.

The application helps extract:

* short summaries
* detailed summaries
* key ideas
* action items
* structured notes
* searchable snippets

Supported content types may include:

* articles
* transcripts
* podcasts
* videos
* meeting notes
* large text documents

## Goals

* reduce time spent consuming long materials
* create practical summaries instead of AI-generated fluff
* provide a fast, tool-oriented interface
* keep architecture simple and maintainable

## Tech Stack

### Client

* React
* TypeScript
* Vite
* Tailwind CSS v4
* TanStack Query
* React Router

### Server

* Node.js
* TypeScript
* Fastify
* SQLite
* Drizzle ORM

## Project Principles

* practical over clever
* boring readable code
* minimal abstractions
* evolution design
* feature-oriented structure
* no fake enterprise architecture

## Development

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```
